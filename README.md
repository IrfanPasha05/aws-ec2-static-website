# AWS EC2 Static Website Hosting

This project demonstrates how to host a simple static HTML website on an AWS EC2 instance using Ubuntu and Nginx.

## 🔗 Live Website
http://3.231.160.86

## 🛠️ Technologies Used
- AWS EC2
- Ubuntu Linux
- Nginx Web Server
- HTML & CSS
- Git & GitHub

## 🚀 Steps to Deploy
1. Launch an EC2 Ubuntu instance
2. Install Nginx
3. Add HTML file in `/var/www/html`
4. Configure security group to allow HTTP (port 80)
5. Access website using EC2 public IP

## 📂 Project Files
- `index.html` – Website homepage
- `README.md` – Project documentation
